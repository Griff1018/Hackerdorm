# Sample dataset notes — Enterprise Buddy

**SYNTHETIC DEMONSTRATION DATA.** No real business, person, address, payment identifier or
transaction is described. Any screen, slide or report that shows this data must carry the same label.

Fictional business used for the demo: a student-run campus snack & drink seller
("Campus Crumb", delivery area: a university campus in Malaysia). Currency **MYR**.
Reporting period **2026-09-01 .. 2026-09-30**; "as of" date **2026-09-30**.

## Conventions

- One **aggregated line per product per day** in sales.csv. A real POS export would usually have
  several lines per order; this simplification keeps the file auditable and is disclosed here.
- `order_id` groups the lines created on the same day into orders of 1–3 lines.
- Dates are calendar dates, ISO `YYYY-MM-DD`. August rows exist so a prior-period comparison is
  possible; they are **outside** the September reporting period and are excluded, not "errors".
- `discount_amount` is a total for the line, not per unit.
